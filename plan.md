# Retail Insights Assistant - Project Plan

## Project Overview
Build a GenAI-powered retail analytics dashboard and conversational assistant using Streamlit, LangChain, and the Gemini API. The application features a 3-column layout for file management, automated visual summary generation, and contextual conversational querying over retail sales data.

## Technical Stack
- **Frontend/UI:** Streamlit (Python)
- **LLM & Orchestration:** Gemini API (`google-genai`), LangChain (`langchain-google-genai`, LangChain core agents)
- **LLM Model:** `gemini-2.0-flash-exp` (fast speeds, high reasoning, multimodal/text support)
- **Data & Visualization:** Pandas, NumPy, Plotly
- **Environment:** Python virtual environment (`venv`)

## Usage Instructions

### Setup
1. Create virtual environment: `python -m venv venv`
2. Activate virtual environment:
   - Windows: `venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`

### Running the Application
1. Run: `streamlit run app.py`
2. Enter your Google API key in the sidebar
3. Upload a CSV file with columns: date, store, family, unit_sales, transactions
4. Click "Make Summary" to generate insights
5. Ask questions in the chat panel

## Expected CSV Schema
The uploaded CSV should contain the following columns:
- `date` - Date of the sales record (YYYY-MM-DD format)
- `store` - Store identifier
- `family` - Product family/category
- `unit_sales` - Number of units sold (numeric)
- `transactions` - Number of transactions (numeric)

## Features
- **Data Validation:** Automatic schema validation for uploaded CSVs
- **KPI Computation:** Total sales, transactions, daily averages, top performers
- **AI-Powered Summary:** Executive summary generated by Gemini
- **Interactive Charts:** Sales trends, family distribution, store performance
- **Conversational AI:** Ask natural language questions about your data
- **Session Persistence:** Maintains state during user session
